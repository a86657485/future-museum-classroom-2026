# “未来已经发生”沉浸式科技馆 Web 与 PPT 主视觉设计规格

日期：2026-08-31  
目标学生：小学四至六年级  
主要使用场景：教师教室大屏讲解 + 学生电脑或平板自主探索  
视觉方向：未来科学馆，高级、沉浸、克制，不使用廉价霓虹科技风

## 1. 项目目标

把七项前沿科技组织成一次可进入、可观看、可思考的数字科技馆体验。学生不是被动浏览一串科技新闻，而是沿一条“探索轨道”进入七个展厅，在每个展厅完成四件事：先观察主视觉，再观看官方演示，随后理解两个关键事实，最后回答一个适龄问题。

网页应让学生感到“未来已经发生”，同时明确区分生成概念图、企业官方演示和已经大规模普及的现实技术。教师可在大屏上连续讲解，学生也可在个人设备上自由选择展厅。

## 2. 交付物

1. 七张由内置 `imagegen` 工具逐张生成的 16:9 无文字高清主视觉，分别对应七个展厅。
2. 七张 1920×1080 的完整 PPT 幻灯片 PNG，在主视觉上叠加准确的中文标题、简短说明、课堂问题和来源标识。
3. 一套响应式 Web 前端，可在教室大屏、电脑和平板上使用。
4. 一份来源清单，记录每项事实、视频和官方页面的出处及访问日期。
5. 本地可运行版本；完成验证后提供可分享的部署版本。官方视频仍依赖网络，页面主体、生成图和文字说明不依赖视频加载成功。

|---|---|---|---|

| Seedance 2.5 | 一句话，也能成为一段电影 | 生成式AI可以把文字、图片、声音等创作材料转化为音视频内容 | 面对一段看起来很真实的视频，我们怎样判断它是否由AI生成？ |

展厅排序不是科技水平排名，而是一条由“数字世界”进入“真实世界”、再进入“未来交通与航天”的叙事线：全模态交互 → 生成创作 → 音视频编程 → 家庭机器人 → 人形机器人 → 飞行汽车 → 可回收火箭。

## 4. 核心体验流程

### 4.1 入馆

首屏只有一句主命题“未来已经发生”、一幅占据主要视野的 `imagegen` 入口主视觉和“进入科技馆”按钮。进入时发生一次约 1.2 秒的轨道推进动画，随后不再持续堆叠装饰性动效。

### 4.2 总览大厅

七个展厅分布在一条可横向探索的轨道上。每个节点显示主题名称、一个简短动词和在线媒体状态。教师可按建议顺序前进，学生可点击任何展厅。

### 4.3 单个展厅

每个展厅使用同一信息结构：

1. 全屏主视觉与一句适龄标题；
2. “先猜一猜”问题，鼓励学生在看视频前表达判断；
3. 官方视频或官方演示入口；
4. 两张事实卡，只放真正帮助理解的事实；
5. “事实边界”提示，说明内容属于现实应用、实验演示还是未来方向；
6. 一道课堂问题；
7. 下一展厅入口。

### 4.4 离馆总结

学生把七项技术归入三个变化：

- AI从回答问题走向完成任务；
- AI从文字走向声音、图像和视频；
- AI从电脑进入机器人、交通与航天等真实世界。

最后留下一个开放问题：“你希望未来科技先帮助人类解决什么问题？”不设置分数排行榜，避免把科技伦理思考变成速度竞赛。

## 5. 双模式设计

### 教师讲解模式

- 支持全屏与键盘左右方向键切换；
- 以固定顺序播放七个展厅；
- 提供醒目的“播放官方视频”“跳过视频”和“下一展厅”；
- 保持文字精简，确保教室后排可读；
- 展示预计用时，便于控制一节课的节奏。

### 学生探索模式

- 可自由选择展厅并查看完成进度；
- 触控目标尺寸适合平板；
- 进度只保存在当前设备，不采集学生身份或个人信息；
- 可以重复观看和修改自己的问题选择；
- 页面不设置登录、聊天、上传或公开分享功能。

## 6. 视觉系统

### 6.1 设计命题

像一次由国家级科技馆策展团队制作的数字展览，而不是儿童卡通网站，也不是常见的深色霓虹仪表盘。

### 6.2 色彩

- 航天器白 `#F5F7F6`：主要背景；
- 深海蓝 `#071B31`：标题、导航和沉浸区域；
- 轨道蓝 `#225FD4`：互动与当前进度；
- 信号橙 `#FF5B35`：关键问题和下一步；
- 冰雾蓝 `#C9DCEB`：信息层次与边框；
- 每个展厅再拥有一种低饱和专属光谱色，但不改变全站主色体系。

### 6.3 字体

- 展览标题：`Songti SC` / 华文宋体风格，用于少量大标题，形成策展感；
- 正文与控件：`PingFang SC` / 思源黑体类系统字体，保证中文阅读；
- 数据与编号：窄体无衬线数字作为辅助，不承担长文本。

字体均提供本机系统回退，不依赖课堂网络加载外部字体。

### 6.4 版式与标志性元素

“探索轨道”是唯一贯穿全站的标志性元素：七个节点既是导航，也是学习进度。大幅主视觉与安静的展签式文字形成对比。圆角只用于媒体窗口和可点击控件，不把所有内容做成相同卡片。

### 6.5 动效

- 入馆仅有一次轨道推进主动画；
- 展厅切换采用短距离景深与淡入；
- 视频和按钮只有必要的状态反馈；
- 遵守 `prefers-reduced-motion`，关闭系统动效时直接切换内容；
- 不使用持续闪烁、快速扫描线或可能分散注意力的粒子雨。

## 7. `imagegen` 资产规范

使用内置 `imagegen` 工具，一项主题发起一次独立生成调用，共七次；不使用命令行 API 回退。

共同要求：

- 用例分类：`scientific-educational`；
- 16:9 宽幅，适合网页首屏和 PPT；
- 电影级科教展览视觉，写实与概念表达平衡；
- 主体明确、背景干净，为中文标题预留可用负空间；
- 七张图保持相同镜头语言、质感、明暗层级和颜色纪律；
- 不在生成图内写中文或英文，不生成品牌 Logo、水印、界面文字或虚构数据；
- 不把概念图描述成产品实拍，真实产品外观与真实演示由官方视频呈现；
- 人形机器人图避免武器化、恐怖化和过度拟人；
- 飞行汽车和火箭图强调工程与安全，不表现危险驾驶或灾难场面。

生成完成后逐张检查主体、构图、手脚结构、机械逻辑、文字伪影和系列一致性。存在明显问题时，只针对问题重新生成对应主题，不整体推翻系列。

## 8. 官方文字与视频资源策略

- 事实优先使用品牌官网、官方技术报告、国家机构页面和官方媒体账号；
- 网页文字以适龄中文转述，不整段复制原文；
- 视频优先使用官方播放器、官方嵌入或打开原页面，不擅自把完整视频复制进项目；
- 每个视频同时提供生成海报图、两句事实摘要和“打开官方页面”按钮；
- 若第三方页面禁止 `iframe`、跨域加载失败或课堂网络不可用，页面不得留白，而是显示海报、摘要、来源和备用链接；
- 所有外部资源标注“来源”“访问日期”和“需要网络”；
- 企业演示明确标注“官方演示”，不写成独立第三方验证结论。

用户已提供并确认纳入的官方页面包括：

- 中国国家航天局可回收火箭页面：<https://www.cnsa.gov.cn/n6758823/n6758838/c10768762/content.html>
- 小鹏汇天飞行汽车页面：<https://www.xiaopeng.com/flyingcar.html>
- SeedRealtime：<https://seed.bytedance.com/zh/SeedRealtime>
- Seedance 2.5：<https://seed.bytedance.com/zh/seedance2_5>

Figure 03、宇树科技 G1 和 Qwen3.5-Omni Audio-Visual Vibe Coding 只使用核验后的官方一手页面或官方账号内容。网页不得把 Figure 的公司家务演示写成“已经进入普通家庭”，不得把 G1 的选配能力或开发演示写成所有设备的默认自主能力，也不得把 Audio-Visual Vibe Coding 写成脱离 Qwen3.5-Omni 的独立产品。

## 9. 前端结构

采用 React + TypeScript 的单页叙事应用。内容与展示分离：七个展厅的标题、摘要、事实、问题、来源和媒体状态集中保存在类型化数据文件中，页面组件只负责呈现和交互。

主要组件：

- `MuseumEntrance`：入馆首屏；
- `MuseumMap`：七节点探索轨道与进度；
- `ExhibitStage`：单个展厅的视觉和文字框架；
- `OfficialMediaPanel`：官方视频、封面和失败备用入口；
- `FactBoundary`：官方演示、实验阶段、现实应用等边界提示；
- `QuestionMoment`：课堂问题与学生选择；
- `TeacherDock`：教师全屏、顺序切换和预计时间；
- `SourceDrawer`：来源与访问日期；
- `ExitReflection`：离馆总结。

网页不依赖后端数据库。学生浏览进度使用 `localStorage`，内容刷新后可恢复；关闭浏览器数据即可清除。

## 10. 响应式与无障碍

- 以 1440×900 教室大屏为主设计尺寸，同时适配 1024×768 平板和 390×844 手机；
- 关键标题在后排可读，正文不使用过小字号；
- 所有操作支持键盘，焦点状态清晰；
- 图像具有准确的中文替代文本；
- 视频若有官方字幕则保留字幕入口，若无则提供文字摘要；
- 颜色对比满足基本可读性，不只依赖颜色传达状态；
- 对自动播放保持克制，带声音的视频必须由用户主动播放。

## 11. 错误与网络状态

- 视频加载中：显示海报、资源标题和“正在连接官方资源”；
- 视频加载失败：显示“课堂网络未能载入视频”，保留摘要与“打开官方页面”；
- 完全离线：七张生成图、文字、问题和来源说明仍可浏览；
- 外部页面变化：来源清单保留原 URL 和访问日期，页面用易修改的数据文件维护；
- 不自动跳转到外站，所有外链明确提示将在新标签页打开。

## 12. 验证与验收标准

### 内容验收

- 七个展厅名称准确，事实均能追溯到官方一手来源；
- 产品演示与现实普及程度没有混淆；
- 中文适合小学四至六年级，不使用堆叠术语；
- 每个展厅都有一个真正需要思考的问题。

### 资产验收

- 七张无文字主视觉全部由内置 `imagegen` 逐张生成并保存到项目；
- 七张 1920×1080 PPT PNG 中文无错字、无截断、无水印；
- 图片系列风格一致，同时能一眼区分七个主题。

### 功能验收

- 教师模式和学生模式均可完成七展厅流程；
- 键盘、鼠标和触控均可使用；
- 视频正常、加载中和失败三种状态均有明确呈现；
- 大屏、平板和手机尺寸无水平溢出或关键控件遮挡；
- 构建成功，没有阻断运行的脚本错误；
- 在真实浏览器中完成入馆、选择展厅、播放或打开官方视频、回答问题、进入下一展厅和离馆总结的完整检查。

## 13. 明确不做

- 不做学生账号、排行榜、聊天机器人、上传照片或公开分享；
- 不自动抓取或镜像整站内容；
- 不把企业演示写成第三方验证事实；
- 不用生成图替代真实产品证据；
- 不为追求“科技感”增加影响课堂阅读的装饰动效。
